# Documentation Policy

**Agent-trigger:** Keeping written documentation true: architecture decision records, runbooks, README upkeep, and the rule that a document contradicted by the system is corrected in the same change. Load when a document goes stale, when making an architectural decision worth recording, and when writing or updating a runbook.

An architectural decision that closes off an alternative is recorded, with the alternatives considered
and why they lost. A decision remembered only by the person who made it is not a decision the team owns.

A runbook is verified by someone who did not write it, following it exactly. Steps that could not be
followed are defects in the runbook.

A document contradicted by the live system is corrected in the same change that discovered the
contradiction. Documentation is load-bearing, and a stale page actively drives wrong decisions.
